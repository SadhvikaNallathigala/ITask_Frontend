# BIZTAB iTASK Owner Portal — Expanded Workflows

The sidebar uses the exact BIZTAB logo image supplied by the user (`public/biztab-logo.png`).

## Run locally (Windows CMD)
1. Extract this ZIP into a new folder.
2. Open CMD in the extracted project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

Requires Node.js 20.9+.

## Included
- Existing owner dashboard, project/task management, team tracker, risks, notifications, reports, and settings.
- Additional starter screens for approvals & evidence, documents & knowledge, suppliers & contracts, budget & resources, audit trail, activity feed, templates & permissions, and integrations.
- Circular floating iTAB chatbot button at bottom-right; opens a compact chat panel.
- Sample data and demo interactions.

## Prototype limitations
The additional screens are frontend starters, not complete production workflows. Authentication, backend persistence, uploads, approval enforcement, role permissions, integrations, audit persistence, and production AI retrieval require backend implementation and tests.
